# Ridiculous at First Glance, Real by the Second

One sentence (190 characters, limit 200): a startup pitch for professional mourners for houseplants — absurd on first hearing, with a payer and a reason that hold up on the second.

> We rent out professional mourners for houseplants: grieving owners pay $40 an hour for a stranger in black to weep over their dead fern, because guilt beats therapy and ferns never complain.

`main.py` (Python 3.13, stdlib only) writes that sentence to `/output/entry.txt`. Deterministic: the same text on every run.
